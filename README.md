# 🎓 Dashboard Academic

An end-to-end academic data analytics project focused on exploring university student data, analyzing academic performance, evaluating student attendance, and developing interactive dashboards using Tableau and Power BI.

## 📌 Project Overview

This project demonstrates an end-to-end data analytics workflow, starting from data inspection and validation to exploratory data analysis, data preparation, and dashboard development.

The project focuses on three main analytical areas: student overview, academic performance, and attendance analytics.

The dashboards are developed using two Business Intelligence tools, Tableau and Power BI, to explore different approaches to data visualization and reporting.

## 🎯 Project Objectives

- Analyze student demographics and distribution across study programs.
- Evaluate academic performance and student achievement.
- Analyze student attendance patterns and statistics.
- Identify trends and insights from academic data.
- Develop interactive dashboards using Tableau and Power BI.

## 📊 Dataset

The project uses a synthetic university dataset designed to represent academic data structures for analytical purposes.

**Dataset Source:**

[Kaggle – Data Universitas Sintesis](https://www.kaggle.com/datasets/selwinsaputra/data-universitas-sintesis)

The dataset is processed and transformed into analytical datasets for dashboard development.

## 🔍 Data Analysis Workflow

### 1. Data Inspection
- Understanding dataset structures.
- Checking data types and dimensions.
- Identifying initial data issues.

### 2. Data Validation
- Checking missing values.
- Identifying duplicate records.
- Validating data consistency.

### 3. Exploratory Data Analysis (EDA)
- Exploring academic data distributions.
- Analyzing student performance.
- Examining attendance patterns.

### 4. Data Preparation
- Cleaning and transforming datasets.
- Preparing analytical datasets.
- Creating datasets for dashboard development.

## 📈 Dashboard Development

Three interactive dashboards are developed using Tableau and Power BI. Both tools use the same analytical datasets to provide comparable insights through different visualization and BI approaches.

### 1. Student Overview Dashboard

Provides an overview of student demographics and academic distribution.

**Key Metrics & Analysis:**
- Total and active students.
- Student distribution by faculty.
- Student distribution by cohort.
- Gender distribution.
- Top study programs by student population.
- Number of courses across study programs.

**Analytical Dataset:** `student_overview.csv`

### 2. Academic Performance Dashboard

Focuses on student academic achievement and performance evaluation.

**Key Metrics & Analysis:**
- Average final grades.
- Grade distribution.
- Student pass and fail counts.
- Student pass rate.
- Academic performance by study program.
- Academic performance by cohort.

**Analytical Dataset:** `academic_performance.csv`

### 3. Attendance Analytics Dashboard

Analyzes student attendance patterns and participation in academic activities.

**Key Metrics & Analysis:**
- Total attendance records.
- Student attendance rate.
- Present, permission, sick, and other attendance records.
- Attendance distribution by study program.
- Attendance comparison by cohort.
- Attendance trends over time.

**Analytical Dataset:** `attendance_analytics.csv`

## 📊 Business Intelligence Tools

### Tableau
Used to develop interactive dashboards, explore data relationships, and present analytical findings through visual storytelling.

### Power BI
Used to develop interactive reports with data modeling, DAX measures, KPI calculations, filters, and drill-through capabilities.

Both tools implement the same three dashboard topics using the same analytical datasets.
