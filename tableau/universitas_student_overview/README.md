# 🎓 Student Overview Dashboard

## 📌 Overview

The Student Overview Dashboard provides a comprehensive overview of university student data, focusing on student demographics, distribution across faculties and study programs, and academic enrollment statistics.

This dashboard is designed to help users understand the composition and distribution of students through interactive visualizations and key performance indicators (KPIs).

## 🎯 Objectives

- Provide an overview of the university's student population.
- Analyze student distribution across faculties and study programs.
- Explore student demographics and cohort distribution.
- Identify study programs with the highest student populations.
- Present academic data through interactive visualizations.

## 🛠️ Tools & Technologies

- Tableau Public
- Python
- Pandas
- CSV Dataset

## 📊 Key Metrics & Analysis

The dashboard covers several key analytical areas:

- **Total Students:** Overview of the total student population.
- **Student Distribution by Faculty:** Comparison of student populations across faculties.
- **Student Distribution by Study Program:** Analysis of student enrollment across study programs.
- **Student Distribution by Cohort:** Overview of students based on admission year.
- **Gender Distribution:** Analysis of student demographics.
- **Top Study Programs:** Identification of study programs with the largest student populations.
- **Courses by Study Program:** Overview of the number of courses across study programs.
