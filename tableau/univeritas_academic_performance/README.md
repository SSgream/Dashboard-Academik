# Academic Performance Dashboard

An interactive university academic analytics dashboard built using **Tableau** to explore student academic performance through grade distributions, faculty comparisons, study program performance, enrollment cohorts, and academic trends.

## Project Overview

The Academic Performance Dashboard provides an overview of student academic performance across faculties and study programs.

The dashboard focuses on analyzing grade distributions, comparing average grades, identifying high- and low-performing study programs and courses, and exploring academic performance trends across different enrollment cohorts and years.

This project demonstrates how academic data can be transformed into interactive visual insights to support data-driven analysis in higher education.

## Dashboard Features

### 1. Key Performance Indicators (KPIs)

The dashboard includes four main indicators:

- **Total Course Records** – Total number of course records included in the analysis.
- **Average Grade** – Overall average student grade on a 0–100 scale.
- **Pass Rate** – Percentage of records meeting the passing threshold.
- **Total Students Evaluated** – Number of distinct students included in the evaluation.

### 2. Data Visualizations

| Visualization | Description |
|---|---|
| Grade Distribution | Shows the distribution of grades across predefined grade ranges. |
| Average Grade by Faculty | Compares average academic grades across faculties. |
| Performance by Enrollment Cohort | Analyzes average grades based on student enrollment year. |
| Top 10 Study Programs by Average Grade | Highlights the ten study programs with the highest average grades. |
| Average Grade by Year | Shows changes in average academic performance across years. |
| Highest & Lowest Performing Courses | Identifies courses with the highest and lowest average grades, including record counts. |

### 3. Interactive Filters

Users can explore the dashboard using the following filters:

- Faculty Name
- Study Program
- Academic Year

These filters allow users to analyze academic performance from different perspectives.

## Key Insights

The dashboard helps users explore several aspects of academic performance:

- Overall student grade distribution and academic performance.
- Differences in average grades across faculties.
- Study programs with relatively higher average grades.
- Academic performance patterns across enrollment cohorts.
- Changes in average grades over different academic years.
- Courses with the highest and lowest average grades.

This project uses a synthetic academic dataset structured around university academic information.

The dataset is designed for analytical and visualization purposes and does not expose actual student personal information.
