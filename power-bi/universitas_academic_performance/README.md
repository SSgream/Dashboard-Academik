Act as a Senior Power BI Dashboard Designer and Data Visualization Specialist.

Create a modern, professional, and interactive Power BI dashboard titled:

# ATTENDANCE ANALYTICS
**University Academic Analytics**

The dashboard should analyze student attendance patterns across faculties, study programs, enrollment cohorts, and academic semesters.

### 1. Dashboard Layout

**Header Section**
- Dashboard title: ATTENDANCE ANALYTICS
- Subtitle: University Academic Analytics
- Clean and professional university analytics branding.

**Filter Section**
Create slicers for:
- Faculty
- Study Program
- Enrollment Year
- Academic Year
- Semester
- Attendance Type

Arrange slicers horizontally or in a compact filter panel.

### 2. KPI Cards

Create four KPI cards:

1. Total Attendance Records
2. Present Rate (%)
3. Absent Rate (%)
4. Total Students

Each card should include:
- Large and readable metric value.
- Short descriptive label.
- Consistent formatting.
- Subtle background and rounded corners.

### 3. Visualizations

**A. Attendance Distribution**
- Donut chart.
- Show the proportion of each attendance category.
- Use distinct colors for each category.
- Display percentages and counts.

**B. Attendance Rate by Faculty**
- Horizontal bar chart.
- Compare attendance rates across faculties.
- Sort descending.
- Use data labels.

**C. Top 10 Study Programs by Attendance Rate**
- Horizontal bar chart.
- Show the 10 highest attendance rates.
- Include attendance record counts in tooltips.

**D. Attendance Trend by Semester**
- Line chart.
- Show attendance rate across academic semesters.
- Ensure chronological sorting.
- Use markers and informative tooltips.

**E. Attendance Rate by Enrollment Cohort**
- Column chart.
- Compare attendance rates across student enrollment years.
- Use chronological sorting.

**F. Attendance Status by Faculty**
- Stacked bar chart.
- Show the distribution of attendance categories across faculties.
- Use consistent category colors.

### 4. Power BI Functionality
- Create DAX measures for all KPIs and calculated rates.
- Use slicers with appropriate relationships.
- Enable cross-filtering between visuals.
- Configure report tooltips.
- Apply conditional formatting where useful.
- Ensure all visuals respond correctly to filters.
- Use appropriate aggregation methods to avoid double counting.

### 5. Visual Style
Use a clean and soft professional design:
- Primary color: Navy blue.
- Background: White and very light gray.
- Accent: Soft blue.
- Attendance categories: Distinct harmonious colors.
- Rounded KPI cards.
- Minimalist typography.
- Consistent margins, spacing, and alignment.

Avoid overly saturated colors, excessive decorations, and crowded visualizations.

### 6. Data Accuracy Requirements
- Use only the actual columns and values in the provided CSV files.
- Do not fabricate attendance categories or fields.
- Define which attendance categories count as present, absent, excused, or sick based on the actual dataset.
- Calculate rates using the correct denominator.
- Use distinct student counts for student-related KPIs.
- Sort semester values chronologically.
- Avoid misleading rankings when record counts are insufficient.

The final dashboard should be polished, interactive, easy to understand, and suitable for a professional Data Analyst portfolio.
